# Vídeo 117 — Onboarding que configura uma escola inteira

## Gancho

“Entregar um sistema sem ensinar a ordem dos cadastros é entregar um quebra-cabeça.”

## Desenvolvimento

**Tela:** primeiro login de uma nova conta de gestão.

**Fala:** “No primeiro acesso, a gestão não cai em um dashboard vazio. Ela entra em um onboarding que explica e valida cada etapa.”

**Tela:** barra com Escola, Modalidades, Salas, Professores e Turmas.

**Fala:** “A sequência acompanha as dependências reais. Primeiro os dados oficiais; depois os cursos, os espaços, os professores e, por último, os horários que unem tudo.”

**Tela:** tentar avançar sem cadastrar um item.

**Fala:** “Não basta clicar em continuar. O sistema consulta o Supabase e só libera a próxima etapa quando o cadastro necessário realmente existe.”

**Tela:** concluir e abrir o dashboard.

**Fala:** “Ao finalizar, a conta é marcada como configurada e os próximos logins seguem direto para o painel.”

## Fechamento

**Fala:** “Onboarding bom reduz suporte porque ensina enquanto configura.”

## Cuidados na gravação

- Usar uma conta de gestão criada apenas para demonstração.
- Não exibir chaves PIX ou dados fiscais reais.
- Mostrar uma validação bloqueando o avanço.
