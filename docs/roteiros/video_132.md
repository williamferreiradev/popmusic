# Vídeo 132 — Área de toque correta na chamada

## Gancho

Se o professor precisa mirar no botão para marcar presença, a interface está atrapalhando a aula.

## Desenvolvimento

Na chamada, os controles de presente, falta e falta justificada tinham uma largura menor que o próprio texto. Isso fazia as palavras se sobreporem e deixava o clique impreciso.

Os três estados agora possuem botões independentes, altura mínima confortável e texto que nunca invade o controle vizinho. No celular eles ocupam uma linha cada; em telas maiores ficam lado a lado.

A mesma solução foi aplicada ao painel administrativo e ao painel do professor, mantendo a experiência consistente para quem realmente fará a chamada.

## Demonstração

1. Abra uma turma na tela de frequência.
2. Mostre os três controles separados.
3. Marque presente, falta e abra a justificativa.
4. Reduza a tela e mostre os botões organizados verticalmente.

## Fechamento

Uma correção pequena de interface elimina cliques errados justamente na operação mais repetida durante a aula.
