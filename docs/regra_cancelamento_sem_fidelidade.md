# Cancelamento sem fidelidade

Regra aprovada em 04/09/2026 para a primeira versão do sistema:

- não existe multa de fidelidade;
- mensalidades pagas não são devolvidas;
- cobranças vencidas antes do cancelamento continuam devidas;
- se houve presença do aluno no mês do cancelamento, a mensalidade daquele mês continua devida;
- se ainda não houve aula e o vencimento do mês ainda não chegou, a cobrança do mês pode ser cancelada;
- cobranças dos meses seguintes são canceladas;
- matrícula, vínculos ativos e contrato são encerrados, preservando todo o histórico;
- o acesso do aluno é desativado após o cancelamento;
- valores já pagos continuam disponíveis para o cálculo de repasse do professor.

O trancamento permanece uma operação diferente: é uma pausa com possibilidade de retorno. O cancelamento encerra definitivamente o vínculo vigente.
